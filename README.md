# HealthDiet

Aplicación para organizar recetas, menús y la compra en un espacio compartido.

La versión actual de la aplicación está en `HealthDiet/`. Consulta [LEEME.txt](HealthDiet/LEEME.txt) para iniciarla, conocer su conexión con Supabase y las instrucciones de prueba, y [ESTRUCTURA.md](HealthDiet/ESTRUCTURA.md) para la organización del código.

La carpeta contiene algunos archivos heredados de versiones anteriores que no forman parte de la aplicación actual. Las recetas, menús y cuentas se guardan en Supabase; este repositorio conserva el código, no una copia de la base de datos.
