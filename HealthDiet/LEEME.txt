HEALTHDIET

Para probar la aplicación, descarga el repositorio completo como ZIP desde GitHub (Code > Download ZIP), descomprímelo y abre index.html en esta carpeta.

Mantén las carpetas css, js e imagenes junto a index.html. No necesitas instalar programas ni Netlify.

Los datos se guardan en el navegador y dispositivo, no en Supabase. Al abrir la aplicación desde otra ubicación o navegador, los datos anteriores podrían no aparecer. Conserva la copia anterior hasta verificarlos. Las marcas de la compra son temporales.

Consulta el README del repositorio para conocer la organización del código.
